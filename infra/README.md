# Frontier / ConDB2 Infrastructure

Server-side stack: ConDB2 REST API, Frontier "launchpad" server, Squid
caching (compose + quadlet configs in this directory).

**Docs (authoritative):** the full runbook — FermiCloud instance setup,
frontier-tomcat, Squid reverse proxy, local workstation Squid cache, manual
upstream client build for bring-up, and end-to-end query testing — lives at
<https://dune.github.io/frontier-condb2/infra/runbook/>
(source: [`docs/infra/runbook.md`](../docs/infra/runbook.md); screenshots
under [`docs/images/`](../docs/images/)).
