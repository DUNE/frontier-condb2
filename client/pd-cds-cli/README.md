# pd-cds-cli

`pd-cds` — Typer command-line client for the ProtoDUNE conditions database.
Thin layer over [`pd-cds-api`](../pd-cds-api/); the native `fn-fileget` comes
from [`pd-cds-api-bin`](../pd-cds-api-bin/).
